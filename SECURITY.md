# Security Policy

## Reporting a vulnerability or accidental disclosure

Do not open a public issue for leaked credentials, private infrastructure,
customer data, or another sensitive disclosure. Use GitHub's private security
advisory reporting for this repository instead.

Include the affected file and revision, the type of exposure, and the minimum
information required to reproduce the problem. Do not include working secrets
or unrestricted private data in the report.

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.
Older tags may not receive backports.

## Repository boundary

This public repository contains generic skills and empty Profile templates.
Real project Profiles, credentials, internal hosts, and product-specific facts
must remain in local ignored storage or a separately controlled private
repository.
