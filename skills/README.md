# Skills

All skills use the `rumo-` namespace while remaining independent of a specific company or product. Project-specific facts are supplied through `rumo-project-profile` and a local profile or optional private profiles checkout.

| Skill | Purpose |
| --- | --- |
| `rumo-remote-ops` | Backup coverage, consistency, protected storage, and layered recovery verification |
| `rumo-debug` | Evidence-led root-cause investigation across source and runtime boundaries |
| `rumo-verify` | Exact change-scope inspection and smallest-sufficient verification |
| `rumo-review` | One-pass read-only engineering review |
| `rumo-coding-guidelines` | Minimal, path-grounded, assumption-aware, verified code changes |
| `rumo-interface` | Compatible, secure, retry-safe, bounded, and operable HTTP/JSON API design and review |
| `rumo-daily-report` | Cross-session incremental Chinese daily reports in a date-based TXT file (manual only) |
| `rumo-database-change-safety` | Safe database migration, repair, cleanup, backup, authorization, and rollback |
| `rumo-filesystem-safety` | Tiered file and directory deletion with boundary checks and no ad hoc backups |
| `rumo-document-writing` | Formal delivery DOCX authoring, revision, formatting, and quality control |
| `rumo-plan` | Durable engineering decisions, alternatives, compatibility, and rollback |
| `rumo-diagram` | Mermaid flowcharts and confirmed topology diagrams with preview and export (optional extra) |
| `rumo-frontend` | Page development, local dev-server troubleshooting, and requested browser evidence (optional extra) |
| `rumo-git-commit` | Commit, branch landing, history cleanup, release, and push workflow |
| `rumo-imagegen` | One-image generation through a configured OpenAI-compatible endpoint (manual only) |
| `rumo-lifecycle-safety` | Safe ownership, retry, cancellation, timeout, shutdown, and cleanup |
| `rumo-linux-inspect` | Read-only Linux hardware inventory or memory inspection (optional extra, manual only) |
| `rumo-offline-delivery-audit` | Offline artifact integrity, provenance, installation, rollback, and acceptance limits |
| `rumo-test` | Evidence-first high-assurance development through an approved specification and reproducible gauntlet |
| `rumo-project-profile` | Private project profile resolution and validation for other skills (manual only) |
| `rumo-handoff` | self-contained handoff document so another session or client can continue (manual only) |
| `rumo-clarify` | lightweight requirement clarification: one round of questions with recommended answers, critical decisions never defaulted |
| `rumo-prose` | Prose quality for comments, diagnostics, logs, docs, prompts, and UI strings |
