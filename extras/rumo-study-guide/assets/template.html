第一章 / 输入、过程、结果

多加一个数，结果怎样变？ P0 能独立解释预计 5 分钟

本章问题：从 1 加到 4 得到多少？终点增加 1，结果也只增加 1 吗？

讲解：每一步都把下一个数加入总数

从 0 开始，每次加入一个整数，直到包含终点 n。这个过程叫累加：总数保留前面各步的结果，再接着加。

术语提示：累加器
用于保存中间总数的变量。本例中的 total 就是累加器；每一步更新后，保留截至当前的和。
教学示例，非实测

只讨论 1 到 20 的正整数。手算和页面模型说明相同的规则，没有测量真实服务的性能。

完整例子：从 1 加到 4

输入 n = 4，初值 total = 0。依次变成 0 + 1 = 1，1 + 2 = 3，3 + 3 = 6，6 + 4 = 10。所以结果是 10。

代码走读：把每一行对回手算

  1. 设定终点，并用 0 保存初值。
  2. range(1, n + 1) 包含 1 到 n。
  3. 每轮将当前整数加到 total。
  4. 打印最终总数；手算预期为 10。
